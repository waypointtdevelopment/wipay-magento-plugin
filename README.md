# Waypoint WiPay for Magento / Adobe Commerce

An independent payment integration project maintained by Waypoint. It is not affiliated with, sponsored by, or endorsed by WiPay.

## Project status

**Research and legacy review only.** This repository is not a current, supported release. The supplied legacy archive targets Magento 2.3.x and reports testing only through 2.3.3. Its code, license/provenance, and old setup/API instructions must be reviewed before any reuse.

## Direction

The intended integration would send shoppers to WiPay's hosted checkout and verify payment responses server-side. The store should not collect card details. Supported Magento and Adobe Commerce versions, API behavior, and test coverage have not yet been selected.
